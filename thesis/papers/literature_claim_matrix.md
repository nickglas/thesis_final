# Literature Claim Matrix

One row per paper note under the topic folders below this file:

- [partitioning/](partitioning/) — distributed / split DNN inference, model partitioning (RQ1 corpus).
- [cloud_native/](cloud_native/) — Kubernetes, container, CNI, RPC, cloud-noise, and benchmarking-methodology sources (RQ1 corpus).
- [service_mesh_security/](service_mesh_security/) — service mesh, sidecar overhead, mTLS, and microservice security (RQ2.1 corpus).
- [confidential_computing/](confidential_computing/) — TEEs, AMD SEV-SNP, Intel TDX, and CVM attack-surface bounds (RQ2.2 corpus).
- [secure_inference/](secure_inference/) — cryptographic and TEE-aware secure DNN inference, activation-privacy attacks.
- [background_or_optional/](background_or_optional/) — contrast / scoping references not in the citation spine.
- [duplicates/](duplicates/) — duplicate copies of canonical paper notes, marked "DUPLICATE - do not cite separately" at the top of each file.

Citation keys are only filled when verifiable against [../references.bib](../references.bib) (or, for the RQ1/RQ2 split files, [../rq12_references.bib](../rq12_references.bib) and [../references_new.bib](../references_new.bib)); unverified keys are marked `TODO: citation key`.

The matrix separates evidence (what the paper actually measures or proves) from interpretation (how it is useful to this thesis). Interpretive claims are tagged **[I]**. Evidence claims are tagged **[E]**.

Each row is also tagged with its role in the thesis argument:

- **[Core]** — load-bearing for the main logical chain (~12–18 papers total). Related-work prose rests on these.
- **[Opt]** — optional. Cite only if it adds a specific point not already covered by a Core paper. May be grouped with a Core paper in a single sentence.
- **[Bg]** — background only. Useful for framing, not for the main argument; can stay out of the thesis without weakening it.

# Thesis Evidence Manifest

This manifest maps every active research sub-question to the result artefacts in [../../results/frozen_new/](../../results/frozen_new/). It is built from the accepted plan ([../../concrete_proposal_plan.pdf](../../concrete_proposal_plan.pdf)), the updated plan ([../../plan.pdf](../../plan.pdf)), and direct inspection of the result folders, CSV row counts, and metadata JSONs.

- Model under test: ResNet-18, batch=1, 1×3×224×224, FP32, CPU-only (all stages).
- Standard repetition: 5 rounds × 200 measured iterations × 5 conditions = 5,000 rows for RQ1 stages; 5 paired passes × 2 conditions × 200 = 2,000 rows for RQ2.1 paired stages.
- "Core" = primary thesis-facing measurement. "Supporting" = sensitivity / ablation / explanatory evidence.
- RQ2.3 is synthesis only: it does not introduce a new deployment, it compares the artefacts of RQ1.5, RQ2.1, and RQ2.2.

## 3. Reproducibility caveats

- **Local kind runs (RQ1.4, RQ1.4b) use `thesis-inference:latest`**, a mutable tag pulled with `IfNotPresent`. The AKS runs (RQ1.5, RQ1.5b, RQ2.1, RQ2.1b, RQ2.2) pin the same code by ACR digest `sha256:d292aef407ee8a15da2bdaa680de1cc24b0975e7de81d27e1fc3a7d128b8736b`. The local results are therefore reproducible only up to whatever image was loaded into the kind cluster at run time; for byte-exact reproduction, pull and re-tag the same digest.
- **Best-effort host controls inside containers.** Thread pinning, OMP / MKL / OpenBLAS thread counts, and CPU affinity are applied inside service pods, but CPU governor and turbo settings are node-level on Linux and are not exposed to pods. RQ1.4 / RQ1.4b try to set them and accept graceful failure; RQ1.5 / RQ1.5b explicitly disable those requests (`set_governor: false`, `disable_turbo: false`) because AKS nodes do not expose them.
- **Image is identical across RQ1.5 → RQ2.2** so cross-stage comparisons are not confounded by application-code drift.

## 4. Measurement caveats

- **RQ2.1 chain5 mTLS overhead (+8.84 ms / +10.74%) is ~2.5× the chain2 overhead (+3.49 ms / +4.62%)** — consistent with sidecar cost scaling with hop count rather than being a single fixed surcharge.
